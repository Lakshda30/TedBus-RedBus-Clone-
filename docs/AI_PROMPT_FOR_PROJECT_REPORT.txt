Project title:
RedBus Clone Using MEAN Stack

Project summary:
This is a bus booking web application inspired by RedBus. It is built using Angular 17 for the frontend and Node.js with Express for the backend. MongoDB with Mongoose is used as the database. The project allows users to search bus routes, view buses, select seats, book tickets, make payments, manage bookings, receive notifications, write reviews, interact with community posts, and use a route planner.

Core technologies:
- Angular 17
- Angular Material
- TypeScript
- RxJS
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- Google Auth Library
- Socket.IO
- Web Push
- Stripe
- Razorpay
- Tailwind CSS / custom CSS

Frontend pages and modules:
- Landing page

- Passenger details page
- Payment page
- Booking success page
- Profile page

- Community page

Frontend features:
- Search buses by source, destination, and date
- Display bus list with timing, ratings, fare, and seat availability
- Seat selection workflow
- Booking summary
- Google login support
- JWT-based authenticated requests using interceptor
- User profile and my bookings section
- Notification settings and language settings
- Real-time notifications
- English and Hindi translation support
- Route planner with route comparison by time, distance, and traffic

Backend modules and APIs:
- Customer routes for login, profile fetch, notification preferences, language update, and push subscription
- Booking routes for booking creation, seat booking, booked seat retrieval, and user bookings
- Route routes for route search and matched buses
- Bus routes for bus operations and schedule updates
- Payment routes for Stripe checkout session, Stripe confirmation, Razorpay order creation, and Razorpay verification
- Post routes for creating, liking, commenting, reporting, and fetching community posts
- Review routes for submitting, editing, voting, reporting, and fetching reviews
- Notification routes for storing notifications, fetching user notifications, marking as read, broadcasting promotions, and retrying failed notifications

Important backend details:
- Server uses Express and Socket.IO
- MongoDB is connected using Mongoose
- JWT is generated after Google credential verification
- Notification service sends booking confirmations and promotional alerts
- Payment attempts are stored separately before booking confirmation
- Demo route data is used as fallback for some city pairs if database data is missing

Project highlights:
- Google-based login and verified user flow
- Secure token-based API access
- Dual payment gateway integration with Stripe and Razorpay
- Notification system with in-app, push, and real-time delivery
- Community posting and travel discussion features
- Review system with helpful votes and report moderation
- Route planner with Google Maps style route comparison
- Multi-language support
